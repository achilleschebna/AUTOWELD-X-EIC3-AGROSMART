# Contribution – Châssis AUTOWELD-X

**Responsable :** Esther Chery

## 1. Description
Conception et modélisation 3D du châssis et du support du système AUTOWELD-X.

## 2. Outil utilisé
- FreeCAD

## 3. Éléments modélisés
- Structure principale du châssis
- Plaque supérieure
- Quatre pieds de support
- Traverses de renforcement
- Cadre supérieur avec traverses internes

## 4. Fichiers
Les fichiers CAO et les exports du châssis seront déposés dans ce dossier.

## 5. Objectif
Fournir une structure de support pour le système de soudage robotisé AUTOWELD-X.
